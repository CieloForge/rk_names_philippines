# Philippines Names Mod

A Transport Fever 3 mod that adds Philippine-based names for towns, streets, and citizens. This mod enhances the game with culturally relevant naming options, purely for cosmetic purposes.

## Description

This mod adds a collection of Philippine-inspired names for towns, streets, and citizen names in Transport Fever 3. It's designed to give players a more authentic regional flavor by replacing generic location names with Filipino names and surnames.

## Features

- **Philippine Town Names**: Adds locally inspired town names throughout the map
- **Philippine Street Names**: Provides street name options with Filipino flair
- **Citizen Names**: Includes person name scripts for players to use in the game
- **Cosmetic Only**: No gameplay changes – purely aesthetic enhancements

## Installation

1. Download the mod package from the Transport Fever 3 mod site
2. Extract the archive into your game's `mods` directory
3. Ensure the mod ID `rk_names_philippines` is recognized by the game

## Requirements

- Transport Fever 3

## Usage

Once installed, the mod will be automatically loaded by the game. You can access the new names through the in-game loading screen or by checking the mod's configuration.
